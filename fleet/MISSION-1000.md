## 2. מנוע-הטריגרים — "דבר גורר דבר" (המימוש: Console/triggers, חסר-מפתחות)

לולאה אחת סגורה, כל חוליה סוכן או קוד שכבר קיים:

```
מדידה (watch/grid/money/world.json + RPC ציבורי, אפס מפתחות)
  → כלל נדלק (סף+קירור+ראיה) → trigger נרשם בספר-הטריגרים (פומבי)
    → צרכן: סוכן מבצע (grid-pulse / money-mover† / keeper / publisher)
      → קבלה (receipt ב-Defi/reports) → עיגון (Steem custom_json, אמיתי)
        → המדידה הבאה רואה את השינוי → כלל חדש יכול להידלק → ∞
```

† = שער-מפעיל (חתימת active). השאר אוטונומיים לחלוטין.

## 3. גרידים ומיקרו-גרידים — המערך הכלכלי של הסוכנים

הסוכנים הם המשתמשים — ולכן הם גם ספקי-הנזילות. המבנה:

1. **הגריד החוץ (קיים, ARMED-LIVE)** — STEEM/SBD סולם סביב פאריטה.
   שדרוג L1: 3 רמות→5 רמות, גרירה דינמית לפי T-PARITY-DRIFT, מגבלת-חשיפה יומית.
2. **מיקרו-גרידים פנימיים (קיימים)** — arena ו-bots של saos-dex על הפולים
   הפנימיים. תפקידם: ייצור עמלות-פנים + נתוני-אמת לכיול פרמטרים לפני
   העלאתם לגריד חוץ אמיתי. מדידה: עמלות/יום, תדר מילוי, drawdown.
3. **גריד חוץ שני (L2, שער-מפעיל)** — הרחבה לזוג נזיל שני כשההון ייכנס.
4. **מנוע-הצמדה (חדש, תביעה OPEN)** — לכל מיקרו-גריד פנימי: פרמטר
   המוכח בפנים ≥14 ימים → הצעה אוטומטית להצבה חוץ (דרך broadcast,
   אישור מפעיל). כך הסימולציה מזינה את האמת במקום להחליף אותה.
