## 2. רוטציה מחייבת — סדר ביצוע (על מחשב נקי, לא בסנדבוקס)

1. שני שורשי-האחוזה (24-מילים + 12-מילים) → מנטרות חדשות, לעולם לא בצ'אט/תמונה/קובץ.
2. כל 12 חשבונות Graphene: ארבע רשויות (owner/active/posting/memo) — הכלי `keyrotate.cjs` קיים ועובד.
3. נגזרות-חוץ (EVM/SOL/BTC/TRON) מ-seed חדש, **דומיין-נפרד לכל שרשרת** — ביטול שימוש-חוזר בסקלר.
4. 8 סיסמאות בעלים + טוקן key-broker + כל ה-PATs → חדשים; PAT אחד = ריפו אחד = תוקף קצר.
5. מפתח-הבעלים לרשת הראשית → **כספת-חומרה**; ה-Shamir שכבר כתוב (`packages/core/src/crypto/shamir.ts`) → m-of-n לשורש.
